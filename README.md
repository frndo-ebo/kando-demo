# Kando Garage

Site institucional da oficina Kando Garage – mecânica geral, preventiva e especializada.

## Estrutura do projeto

- public/   -> Front-end (HTML, CSS, JS)
- server/   -> Back-end (Node.js + Express)

## Como executar

Front-end: abra o arquivo public/index.html no navegador.

Back-end:
cd server
npm install
npm start

O servidor roda em http://localhost:3000 e serve os arquivos estáticos de public/.

Endpoint:
- POST /contact  (placeholder para formulário de contato)
